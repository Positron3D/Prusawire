# AntHead Mount

This is an experimental x-carriage/mount for AntHead on the Prusawire 2026.R1.  Use these files in lieu of the stock left and right x-carriage files.  You may source the rest of AntHead from the [PrintersForAnts Github](https://github.com/PrintersForAnts/AntHead).

If you use this, please give us feedback on either Discord or in GitHub issues! We are happy to help revise the mount as needed.
